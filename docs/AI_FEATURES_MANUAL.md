# AI Features Manual

Version: 1.1
Updated: 2026-06-14

## 1. AI Analysis

This AI reads an alumni profile and a job post, then gives a short explanation of why the profile fits or does not fit the role. It highlights the main strengths, the main gaps, and a plain-language summary for the user.

## 2. AI Matching

This AI compares an alumni profile against a job posting and gives a match score from 0 to 100. Higher scores mean the profile is more aligned with the job requirements, while lower scores mean there is less direct fit.

## 3. AI Profanity Filter

This AI checks forum posts and comments for offensive words and replaces them with asterisks before the content is shown. If the AI is unavailable, the system still uses a built-in fallback list to catch common profanities.

End of manual.
